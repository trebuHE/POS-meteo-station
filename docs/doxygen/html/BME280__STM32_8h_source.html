45/* Configuration for the BME280
46
47 * @osrs is the oversampling to improve the accuracy
48 * if osrs is set to OSRS_OFF, the respective measurement will be skipped
49 * It can be set to OSRS_1, OSRS_2, OSRS_4, etc. Check the header file
50 *
51 * @mode can be used to set the mode for the device
52 * MODE_SLEEP will put the device in sleep
53 * MODE_FORCED device goes back to sleep after one measurement. You need to use the BME280_WakeUP() function before every measurement
54 * MODE_NORMAL device performs measurement in the normal mode. Check datasheet page no 16
55 *
56 * @t_sb is the standby time. The time sensor waits before performing another measurement
57 * It is used along with the normal mode. Check datasheet page no 16 and page no 30
58 *
59 * @filter is the IIR filter coefficients
60 * IIR is used to avoid the short term fluctuations
61 * Check datasheet page no 18 and page no 30
62 */
63
64int BME280_Config (uint8_t osrs_t, uint8_t osrs_p, uint8_t osrs_h, uint8_t mode, uint8_t t_sb, uint8_t filter);
